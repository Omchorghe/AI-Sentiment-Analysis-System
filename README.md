# AI Sentiment Analysis System

A full-stack sentiment analysis web application built using React JS, FastAPI, NLP, and Machine Learning.

## Features
- Text Sentiment Analysis
- File Upload Analysis
- Twitter/X URL Analysis
- React Frontend
- FastAPI Backend

## Tech Stack
- React JS
- FastAPI
- Python
- Scikit-learn
- NLTK
